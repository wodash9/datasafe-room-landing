# PRD V0 — DataSafe Room Landing

## Objetivo

Validar demanda por una propuesta tipo dataspace industrial sin usar lenguaje técnico de entrada: salas controladas de colaboración de datos para empresas reticentes a compartir datos.

## Público

- Dirección industrial / gerencia.
- Supply chain y compras.
- Sostenibilidad / ESG.
- Calidad.
- IT / seguridad.

## Promesa

Colaborar con clientes/proveedores usando datos sensibles con más control y trazabilidad, sin entregar datos brutos ni abrir sistemas indiscriminadamente.

## Alcance V0

- Landing estática.
- Copy orientado a PCF/sostenibilidad, calidad, logística, trazabilidad y planificación.
- CTA `mailto:hola@etharlia.com`.
- Sin formularios ni tracking.

## No objetivos

- No prometer cumplimiento legal completo.
- No prometer seguridad absoluta o control total.
- No demostrar producto real ni procesamiento de datos.
- No conectar OT/IT.
